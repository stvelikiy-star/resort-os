# THREE CROWNS — CORE DATA INTAKE

Цель этой папки — собрать только реальные операционные данные, необходимые для запуска первого рабочего ядра Resort OS.

Не требуется вручную заполнять эти шаблоны, если исходные данные уже существуют в другом виде.

Допустимые исходники:

- Excel / CSV;
- фотографии таблиц;
- скриншоты старой PMS/шахматки;
- Word/PDF;
- сообщения/текст;
- фотографии прайса;
- выгрузка из существующей системы.

Главное правило: данные не додумываются. Неизвестное оставляется пустым до подтверждения.

## P0 — нужно первым

1. `rooms.csv` — фактический номерной фонд.
2. `rates.csv` — фактические цены и периоды действия.
3. `reservation_rules.md` — реальные правила бронирования/подтверждения/оплаты.

После получения этих данных можно безопасно строить первый рабочий vertical slice:

ROOMS → AVAILABILITY → RESERVATION REQUEST → HUMAN CONFIRMATION → RESERVATION → PMS GRID.

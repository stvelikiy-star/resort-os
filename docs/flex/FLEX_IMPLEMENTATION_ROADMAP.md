# MARINA SMART FLEX 2.0 — дорожная карта

Только проект. Заменяет порядок из `FLEX_IMPLEMENTATION_PLAN.md` там, где они расходятся (см. COMMERCIAL §0).

## P0 — безопасная основа (поведение клиентов не меняется)
1. Мультитенантность в тесте: `MARINA_TENANT_CONTEXT_ENABLED=true`, тест двух отелей. 2. RLS-каркас для будущих `flex_*`. 3. Таблицы каталога/подписок (пустые), grandfathered-подписки. 4. Entitlement-слой в режиме SHADOW. 5. Неизменяемые журналы (`flex_change_log`, `flex_events`).
## P1 — коммерческое ядро
1. Каталог SKU/функций/лимитов/пакетов. 2. Подписки с позициями и ручное подключение. 3. Движок счетов и пересчёта (пропорции, лимиты). 4. Платежи: реестр, аллокации, ручная оплата с документом, кредит-ноты. 5. Автомат состояний + планировщик в режиме «было бы». 6. Super Admin (отели, каталог, подписки, аудит). 7. Раздел «Подписка и счета» у владельца. 8. ENFORCE на одном пилотном отеле.
## P2 — рост
1. Адаптер провайдера + QR + вебхуки (после выбора и договора с провайдером). 2. Напоминания. 3. Агенты, правила, комиссии, выплаты, кабинет. 4. Аналитика и когорты. 5. Сезонные планы, акции, пакеты. 6. Mobile-версия центра.

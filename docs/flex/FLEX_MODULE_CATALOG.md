# MARINA SMART FLEX — реестр функций и модулей

Колонка «Статус» — только то, что подтверждено кодом в `main` @ 2642eed. «Готово (код)» не равно «проверено в бою»: тесты и реальные интеграции отдельно.
Ключи секций взяты из `section_permissions.py` (26 шт.).

## A. Ядро — нельзя отключать (входит в базовый тариф 10 000 сом/мес)
| Ключ | Что | Статус |
|---|---|---|
| PMS | шахматка, комнаты, блокировки | Готово (код) |
| RESERVATIONS / REQUESTS | брони и заявки, заселение, выселение, фолио | Готово (код) |
| RATES | тарифы и цены номеров | Готово (код) |
| OPS | горничные, техники, задачи | Готово (код) |
| DASHBOARD | панель руководителя | Готово (код) |
| STAFF / SETTINGS / HOTEL_RULES | персонал, права, настройки, правила | Готово (код) |
| FINANCE (учёт гостевых платежей и документов) | платежи гостей, фолио | Готово; провайдеры отключены флагами (`payment_operations=false`) |
| AUDIT | журнал действий (`AuditLog`) | Готово (код) |

Причина неотключаемости: прерывание нарушает активные брони, платежи и документы.

## C. Зависимости (правила каталога)
- Нельзя включить модуль, если не активна зависимость; нельзя отключить зависимость, пока активен зависимый модуль (UI предупреждает, сервер запрещает).
- Склад ← Кухня ← Ресторан. Маркетинг ← CRM. Channel Manager ← PMS + RATES. ИИ ← канал общения.

## D. Что нужно подтвердить до продажи (не считать готовым)
Booking.com (двусторонняя синхронизация), платёжные провайдеры (mkassa и др.), NFC, ИИ-провайдеры: **нет подтверждения в коде и тестах**.

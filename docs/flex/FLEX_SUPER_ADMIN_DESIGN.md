# MARINA FLEX SUPER ADMIN — проект коммерческого центра

Только проект; отдельный контур, не `OWNER` отеля. Стиль Future Luxury 2.0.

## 1. Существующая реализация
Нет платформенной роли и экранов. Есть шаблон админ-интерфейса (`apps/admin`) и компонент `FutureLuxuryAppearance`.

## 2. Роли платформы
`SUPER_ADMIN` (всё), `BILLING` (счета, платежи, сверка), `SALES_MANAGER` (агенты, комиссии, КП), `AUDITOR` (только чтение). Обязательно: 2FA, отдельные сессии, журнал входов, IP-ограничения по решению владельца.

## 3. Разделы
1. **Гостиницы**: таблица (отель, тариф, активные функции, сумма подписки, состояние, долг, агент); карточка — вкладки «Подписка», «Функции», «Счета», «Журнал», «Агент».
2. **Каталог функций**: модули → функции → SKU; цены, типы цен, лимиты, зависимости, пробные периоды, доступность (AVAILABLE/BETA/PLANNED), пакеты, акции. Версионирование: изменение создаёт новую версию, старые подписки не затрагиваются.
3. **Биллинг**: счета, QR/платёжные намерения, платежи, события провайдера, карантин, дебиторка, возвраты, сверка, журнал финансовых операций.
4. **Агенты**: сеть, подключённые отели, продажи функций, правила комиссий, начисления, выплаты, балансы, KPI.
5. **Подписки**: продление, приостановка, восстановление, сезонные планы, ручные корректировки (всегда с причиной и сроком), ручная разблокировка.
6. **Аудит**: кто/когда/какому отелю/на каких условиях подключил, изменил, отключил; экспорт; неизменяемый.
7. **Аналитика**: см. ANALYTICS.

## 4. API-контракты (основные)
```
GET  /api/v1/flex/properties?state=&agent=&q=
GET  /api/v1/flex/properties/{id}
POST /api/v1/flex/properties/{id}/items            {sku, qty, startsAt, endsAt, priceOverride?, reason}
POST /api/v1/flex/properties/{id}/state            {action: SUSPEND|REACTIVATE|EXTEND_GRACE, reason, until}
GET  /api/v1/flex/catalog                          POST /catalog/skus  PATCH /catalog/skus/{id}  (новая версия)
POST /api/v1/flex/invoices/{id}/issue              POST /invoices/{id}/credit-note
POST /api/v1/flex/webhooks/{provider}              (подпись, идемпотентность)
GET  /api/v1/flex/agents  POST /agents  POST /agents/{id}/payouts
GET  /api/v1/flex/analytics/{metric}?from=&to=&dims=
GET  /api/v1/flex/audit?property=&actor=&action=
```
Все изменения: проверка роли, транзакция, запись `flex_change_log`, заголовок `Idempotency-Key`.

## 5. Мобильная версия
Список отелей карточками, быстрые действия (продлить/разблокировать), push-уведомления о неоплатах, тёмная/светлая тема.

## 6. Приёмка
Нет доступа у ролей отеля и агентов; каждое действие в аудите; изменение цены не меняет текущие подписки; ручная разблокировка ограничена по сроку; все экраны на 320–1440 px, RU/KG/EN.

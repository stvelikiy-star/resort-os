# MARINA SMART FLEX — интерфейсы

Только проект. Реализация — по утверждённым макетам (сначала визуал, затем код). Оформление — в языке MARINA/KÖL-админок: тёмная панель, карточки, плитки показателей, цветные статусы.

## MARINA SUPER ADMIN (отдельное приложение/контур, свои пользователи)
1. **Обзор**: MRR, ARR, ARPU, churn, число отелей по статусам, выручка по модулям.
2. **Отели**: список; карточка отеля — тариф, подключённые модули, сроки, статус, счета, журнал.
3. **Каталог и цены**: модули, зависимости, цены за месяц/сезон, статусы AVAILABLE/BETA/PLANNED.
4. **Тарифы**: базовый 10 000 сом/мес, составные планы.
5. **Предложения**: индивидуальное КП (модули, цена, скидка, срок, ссылка для владельца).
6. **Ручное управление**: включить модуль на срок, пробный доступ, продление, отключение; причина обязательна.
7. **Платежи и счета**: счета, ручная отметка оплаты с документом.
8. **Журнал**: кто, что, когда, до/после. Фильтры по отелю и действию.

## OWNER отеля (внутри существующей админки, раздел «Подписка»)
1. Текущий тариф, подключённые модули, срок действия, стоимость.
2. Каталог дополнительных возможностей: карточка модуля (что даёт, цена, зависимости, статус «в разработке»).
3. Кнопки «Запросить подключение / продлить / отключить» — создают запрос, не включают сразу.
4. История начислений и платежей.
5. Сезонное управление: включить модуль на сезон с датами; предупреждение за N дней до окончания.
6. Предупреждения: GRACE-баннер; модуль READ_ONLY показывает «история доступна, новые операции — после продления».

## Поведение заблокированного модуля
Пункт меню виден с замком и пояснением (клиентская подсказка), сервер при прямом запросе отвечает `MODULE_NOT_ENTITLED`. Мобильное приложение и API ведут себя так же.

## Доступность и адаптив
Проверка на 320/375/390/430/1440 px, RU/KG/EN, зона нажатия не менее 44 px; тексты KG/EN вычитывает носитель.

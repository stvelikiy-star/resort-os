# Dining acceptance checklist

- [ ] Included meal rights stored per stay/date/meal with adult/child portions.
- [ ] Chef can see today/tomorrow/week production totals.
- [ ] Chef can drill into room/guest rows and departure notes.
- [ ] Cutoff locks guest meal changes one hour before configured meal start.
- [ ] Room-service delivery fee is visible and separate.
- [ ] Waiter sees own/unassigned/ready queues.
- [ ] Table booking conflicts are rejected transactionally.
- [ ] Guest seating is tied to Stay, not room code.
- [ ] Move-table operation is conflict-safe and audited.
- [ ] Included meals never create Payment records.
- [ ] Paid food/room-service can create folio charges without pretending money was received.
- [ ] Full audit and regression pass completed.

# MARINA STAFF — мобильный клиент (начальный прототип)

Изолированный Expo / React Native проект. Создан отдельно от существующих `apps/staff`, API и PostgreSQL.

## Проверяемое состояние
- Реализован **только демонстрационный локальный UI**: роли горничной, техника, ресепшена; список и статусы задач; вкладки.
- Никаких реальных учётных записей и подключения к MARINA API.
- Никакой записи в базу. Демо-изменения статуса существуют исключительно в памяти приложения.
- Авторизация, гостиничный QR onboarding, push, фотографии, локализация и offline sync **ещё не реализованы**.
- Сборка и типизация **не проверялись** на CI или устройствах.

## Запуск локально
```sh
cd apps/mobile
npm install
npx expo install --fix
npm run typecheck
npm start
```
Требуется Node.js совместимой с Expo SDK 58 версии. Для тестов на устройствах использовать Expo Go/совместимый development build.
